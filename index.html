Colinha de sintaxe: os 6 pontos de atenção de hoje

Antes de abrir o LeetCode, passe o olho nesses 6 contrastes. Eliminar esses erros pequenos libera sua cabeça para pensar só na lógica do algoritmo.

1. Comparação vs. atribuição (e return)

Um = guarda valor. Três === comparam. E return nunca usa =.

if (a = b) { return = prefix; }
if (a === b) { return prefix; }

2. Índice vs. valor dentro do array

i e j são posições (0, 1, 2). O dado de verdade está em nums[i].

if (i + j === target) return (i, j);
if (nums[i] + nums[j] === target) return [i, j];

3. Tipo do dado antes do método

.split('') só existe em string, não em number nem em string[].

let rev = x.split('').reverse().join(''); // x é number
const str = x.toString(); const rev = str.split('').reverse().join('');

4. Limite do loop com .length

Sempre confira a grafia de length e qual variável está crescendo no for.

for (let i = 0; i < s; i++) for (let j = 0; i < nums.lenght; j++)
for (let i = 0; i < s.length; i++) for (let j = i + 1; j < nums.length; j++)

5. Onde colocar o return no loop

return encerra a função na hora. Só vai dentro do for quando quiser parar cedo.

for (let i = 0; i < s.length; i++) { total += values[s[i]]; return total; // para na 1ª letra! }
for (let i = 0; i < s.length; i++) { total += values[s[i]]; } return total; // só depois do loop

6. Objetos com vírgula, Record e Map

Dentro de { ... } separe chaves com vírgula. Use Record para tabela fixa e Map para buscas dinâmicas.

const v: Record<string, number> = { I: 1; V: 5; };
const v: Record<string, number> = { I: 1, V: 5 }; const visto = new Map<number, number>();
